
# Job Recruitment Portal System

## Project Overview
The Job Recruitment Portal System is a Java-based application developed using Object-Oriented Programming concepts. It provides a platform for job seekers and recruiters to manage job-related activities.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Exception Handling

## Main Features

### 1. User Registration and Login
- User registration
- User login
- Role-based access for Job Seekers and Recruiters

### 2. Job Seeker Module
- View and manage user profile
- Search for available jobs
- View job details
- Apply for jobs
- Track applications

### 3. Recruiter Module
- Recruiter account management
- Post job opportunities
- Manage job postings
- Review applications

### 4. Application Management
- Manage job applications
- Review application details
- Handle application status
